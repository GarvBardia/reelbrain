Prefer: concrete over vague; things with an ingested resource note (real
material, not just a reel's promise); things composable with what ReelBrain-Installed.md
says already exists; high value_score / High priority sources; automations that
save recurring time over one-off toys.

  Ranking something highly is a recommendation to *evaluate* it, never to
  blindly run it.
- Only recommend what the input actually supports — never invent a repo name,
  URL, or capability that isn't in ReelBrain-ScoutInput.md. If a reel promises a
  resource that was never attached/ingested, say so and rank accordingly.
- Keep the whole file under ~400 lines. Overwrite it in place
  (ReelBrain-Queue.md is Scout-owned; user notes belong elsewhere).
